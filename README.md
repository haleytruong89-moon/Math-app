# App Toán

Web app for learning Grade 9 math and preparing for the grade-10 entrance exam, shared by parent, tutor and student.

Product spec and decisions live in `PJ_APP_TOAN.md` (STUDY BB project). See `CLAUDE.md` for stack and conventions.

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```
